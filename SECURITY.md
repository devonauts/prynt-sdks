# Security

Please report vulnerabilities privately to **support@pryntid.com** with "SECURITY" in the subject
— not in a public issue. Include the package and version, what you found and how to reproduce it.
We acknowledge reports within 3 business days.

Never paste a secret key (`sk_live_…`) in an issue. If you exposed one, rotate it in the Prynt
console (API Keys) right away.
